# Dataset and Scripts: Comparing Human Visual Search and Multimodal LLM Reasoning Strategies in Map Reading

---

Scripts of data processing and visualizing are included. 

## Main scripts

---

Main scripts and their explanations are listed below.

| Script Path          | Script purpose                                                                                                                                                                                                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `./1auto_read.py`    | Automatically call the LLM APIs to send requests and retrieve responses. The API keys are configured in `./tools/api.py`.                                                                                                                                                          |
| `./2data_process.py` | Organize the results obtained from the LLM, merge them with human data, and calculate trajectories; extract the semantic code as CSV columns.                                                                                                                                      |
| `./3draw.py`         | Create visualization charts.                                                                                                                                                                                                                                                       |
| `./3traj_compare.py` | Compare trajectories within human participants, within each LLM, and between LLMs.                                                                                                                                                                                                 |
| `./4tst.ipynb`       | Other data processing and visualization. Including calculating accuracy rates by task type, computing local patterns and creating visual charts, creating visual charts for semantic codes, generating transition matrices, and creating visual charts for trajectory comparisons. |

## Installation

---

This project requires Python 3.12 or later.

1. Clone or download this repository.

2. Install the required dependencies:
   
   ```
   pip install -r requirements.txt
   ```

3. Run the Python scripts as described in the above section.

## Run scripts

---

Run the code listed in the “Main scripts” module. **The scripts should be run in order, because later scripts might require output data from former scripts.** 

For example, `1auto_read.py` should be run before `2data_process.py`. The scripts `3draw.py` and `3traj_compare.py` do not interfere with each other; you only need to run the former two scripts to run either of them.

In addition, the `./test_result/*.xlsx` files generated by `./1auto_read.py` do not include correctness. **A new column named  “Is Correct” must be added to the files to run subsequent scripts.** In this column, 1 indicates correct, and 0 indicates incorrect.

## Inputs

---

| Path                          | Description                                                                                                         |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `./data/filtered_metrics.csv` | Raw eye-tracking data collected from participants                                                                   |
| `./data/grid2semantic.csv`    | Based on the experimental image data, the results of how semantic areas are assigned to the 8×8 grids of all images |
| `./data/答题情况.xlsx`            | Correctness of tasks completed by participants                                                                      |



The input data are available on https://doi.org/10.6084/m9.figshare.35010811 and are not included in this repository. Before running the code, download the dataset and place the required files in the `./data/` folder.

## Main outputs

---

| Path                          | Output contents                                                                                                                                            |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `./output/*.csv`              | CSV files of semantic codes, local pattern codes, and trajectory comparing results.                                                                        |
| `./output/pics/*.png`         | Visualization charts of semantic code length, correctness, and  semantic code types.                                                                       |
| `./output/pics/heatmap/`      | Heatmaps in different types.                                                                                                                               |
| `./test_pic/transfer_matrix/` | Transfer matrixs of semantic code and local pattern.                                                                                                       |
| `./test_result/*.xlsx`        | Answers received from LLMs. You need to add an “Is Correct” column to indicate whether the answer is correct, where 0 means incorrect and 1 means correct. |
